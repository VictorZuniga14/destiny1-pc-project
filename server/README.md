# destiny1-server

Servicios comunitarios necesarios para soportar el cliente PC.

## Componentes previstos

- Authentication
- Accounts
- Characters
- Inventory
- Activities
- Sessions
- World/Activity state

## Principio

Implementar únicamente los servicios que hayan sido demostrados como necesarios por el flujo del cliente.

No crear una API enorme antes de conocer el protocolo real.
