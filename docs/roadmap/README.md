# Roadmap técnico

## Milestone 1 — Network discovery

Objetivo: comprender una sesión mínima de Destiny 1.

Orden:

1. Handshake.
2. Session login.
3. Session state.
4. Keepalive.
5. NAT.
6. Activity state.

Resultado esperado: documentación y un prototipo capaz de interpretar una sesión mínima.

## Milestone 2 — Client startup

Objetivo: ejecutar el cliente en PC y alcanzar una pantalla funcional de Destiny 1.

## Milestone 3 — Account flow

Objetivo: conectar un cliente experimental con servicios comunitarios y obtener una cuenta/personaje.

## Milestone 4 — Orbit

Objetivo: completar el flujo de login hasta Orbit.

## Milestone 5 — First multiplayer test

Objetivo: conectar dos clientes y demostrar comunicación entre jugadores.

## Milestone 6 — Activities

Expandir progresivamente a destinos y actividades.

## Regla

Cada milestone debe producir una prueba reproducible antes de avanzar.
